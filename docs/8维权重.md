# 六维权重风险评分算法（优化版）

> 本文档描述基于 Hyperliquid 永续合约跟单项目的策略风险评分算法，用于筛选高安全性的盈利策略进行跟单。

---

## 一、新增指标定义与计算方式

在原有六维基础上，补充以下关键统计指标，用于增强评分体系的全面性：

| 指标 | 定义 | 计算方式 |
|------|------|---------|
| **总损益（Total PnL）** | 已平仓（已实现）与未平仓（未实现）头寸的盈亏总和 | `Total PnL = Realized PnL + Unrealized PnL` |
| **已实现损益（Realized PnL）** | 所有已平仓头寸的实际盈亏，扣除手续费及资金费用 | `Σ(平仓收益 - 开仓手续费 - 平仓手续费 - 资金费用)` |
| **投资回报率（ROI）** | 已实现损益与产生该损益所用总产量的比率 | `ROI = Realized PnL / 累计开仓名义本金 × 100%`<br>（累计开仓名义本金 = Σ 每笔已平仓交易的合约数量 × 开仓价格） |
| **胜率（Win Rate）** | 盈利交易笔数占总交易笔数的百分比 | `Win Rate = 盈利交易笔数 / 总交易笔数 × 100%` |
| **交易量（Trade Count）** | 统计期间内的成交总笔数（订单簿每笔成交计为1笔） | 直接统计交易记录条数 |

## 二、综合风险评分框架

### 权重分配（总和 100%）

| 排序 | 维度 | 权重 | 核心逻辑 |
|------|------|------|---------|
| 1 | 市场风险（Market Risk） | 20% | 最大回撤越小越安全 |
| 2 | 流动性风险（Liquidity Risk） | 10% | TVL 越高越安全 |
| 3 | 集中度风险（Concentration Risk） | 10% | 运行越久越可信 |
| 4 | 波动性风险（Volatility Risk） | 10% | 夏普比率越高越安全 |
| 5 | 历史表现风险（Performance Risk） | 20% | APR + 胜率盈亏比组合 |
| 6 | 盈利能力（Profitability） | 10% | ROI + 单位交易量损益 |
| 7 | 策略可信度（Credibility） | 10% | 交易量 + 修正后胜率 |
| 8 | LLM 综合判断（AI Risk） | 10% | AI 多因子综合评估 |

> 最终综合风险评分 = 各维度得分 × 权重的加权和，**分值越高代表策略越安全、越值得跟单**。

---

## 三、各维度评分函数详解

### 维度 1：市场风险（权重 20%）

- **输入**：`max_drawdown`（最大回撤百分比，0~100）
- **评分**：
Score_MarketRisk = clamp(100 - max_drawdown, 0, 100)

text
- **逻辑**：回撤越大，风险越高。完全亏损（100%）得0分，无回撤（0%）得100分。

---

### 维度 2：流动性风险（权重 10%）

- **输入**：`tvl`（总锁仓量，单位 USDT）
- **评分**：
Score_LiquidityRisk = clamp((tvl - 500000) / (5000000 - 500000) × 100, 0, 100)

text
- **阈值**：
- TVL < 50万 → 0分（流动性极差）
- TVL ≥ 500万 → 100分（流动性充足）
- 中间线性插值。

---

### 维度 3：集中度风险（权重 10%）

- **输入**：`days_running`（策略运行天数）
- **评分**：
Score_ConcentrationRisk = clamp((days_running - 180) / (365 - 180) × 100, 0, 100)

text
- **阈值**：
- 运行 < 180天 → 0分（历史不足，不可信）
- 运行 ≥ 365天 → 100分（经历充分市场周期）

---

### 维度 4：波动性风险（权重 10%）

- **输入**：`sharpe_ratio`（夏普比率）
- **评分**：
Score_VolatilityRisk = clamp((sharpe_ratio + 5) / (3 + 5) × 100, 0, 100)

text
- **阈值**：
- Sharpe ≥ 3 → 100分（风险调整后收益极佳）
- Sharpe ≤ -5 → 0分
- 中间线性插值。

---

### 维度 5：历史表现风险（权重 20%）

本维度由 **APR 评分** 与 **胜率-盈亏比组合评分** 各占 50% 构成。

#### 5.1 APR 评分
- **输入**：`apr`（年化收益率，百分比）
- **评分**：
Score_APR = clamp((apr + 100) / (100 + 100) × 100, 0, 100)

text
- **阈值**：APR ≥ 100% 得100分，APR ≤ -100% 得0分。

#### 5.2 胜率-盈亏比组合评分
- **输入**：`win_rate`（胜率，小数）、`avg_profit`（平均盈利）、`avg_loss`（平均亏损）
- **计算盈亏比**：`RR = avg_profit / avg_loss`（若 avg_loss=0，则 RR 视为极大）
- **评分逻辑**（基于交易策略类型）：
高胜率 + 合理盈亏比 → 稳定复利基础
if win_rate > 0.55 and RR > 1.5:
Score_Comb = 85 + min(15, (win_rate-0.55)200 + (RR-1.5)10)

低胜率 + 高盈亏比 → 突破策略可行
elif win_rate < 0.45 and RR > 2.5:
Score_Comb = 60 + min(25, (RR-2.5)*10)

正期望值（期望收益 > 0）
elif (win_rate * avg_profit - (1-win_rate) * avg_loss) > 0:
Score_Comb = 40 + min(40, (期望值 / avg_loss) * 100)

负期望 → 低分
else:
Score_Comb = max(0, (期望值 / avg_loss) * 50 + 30)

text
> 期望值 = win_rate × avg_profit - (1-win_rate) × avg_loss

#### 5.3 历史表现最终得分
Score_PerformanceRisk = (Score_APR + Score_Comb) / 2

text

---

### 维度 6：盈利能力（权重 10%）

本维度综合 **ROI** 与 **单位交易量损益**，衡量策略的资本效率和每笔交易质量。

- **输入**：`roi`（百分比）、`total_pnl`（总损益）、`trade_count`（交易量）
- **ROI 评分**：
Score_ROI = clamp((roi + 50) / (100 + 50) × 100, 0, 100)

text
（基准范围：-50% ~ 100%）
- **单位交易量损益**：`avg_pnl_per_trade = total_pnl / trade_count`
- **单位交易量损益评分**（基准范围：-10 ~ 50 USDT/笔）：
Score_PerTrade = clamp((avg_pnl_per_trade + 10) / (50 + 10) × 100, 0, 100)

text
- **盈利能力最终得分**：
Score_Profitability = Score_ROI × 0.6 + Score_PerTrade × 0.4

text

---

### 维度 7：策略可信度（权重 10%）

本维度评估统计样本的充足性以及胜率的有效性（结合盈亏比修正）。

- **输入**：`trade_count`、`win_rate`、`RR`（盈亏比）
- **交易量评分**（样本量越大越可信）：
if trade_count < 30:
Score_Volume = trade_count / 30 × 50
elif trade_count < 100:
Score_Volume = 50 + (trade_count - 30) / 70 × 30
else:
Score_Volume = 80 + min(20, (trade_count - 100) / 100 × 20)

text
- **修正胜率评分**（防止“小赚大亏”的高胜率假象）：
adjusted_win_rate = win_rate × min(1, RR / 1.5)
Score_WinRate = clamp(adjusted_win_rate × 100, 0, 100)

text
- **策略可信度最终得分**：
Score_Credibility = Score_Volume × 0.5 + Score_WinRate × 0.5

text

---

### 维度 8：LLM 综合判断（权重 10%）

- **输入**：ROI、APR、最大回撤、TVL、夏普比率、运行时长等全部可用指标
- **输出**：LLM 基于综合推理给出 0~100 的风险评分，**分值越高代表策略越安全**。
- **评估要点**：
- 市场感知能力
- 技术分析能力
- 智能风控水平
- 宏观策略适配性
- 该维度作为独立的人工智能补充判断，与其他维度共同构成最终评分。

## 四、综合评分公式
综合风险评分 =
Score_MarketRisk × 0.20 +
Score_LiquidityRisk × 0.10 +
Score_ConcentrationRisk × 0.10 +
Score_VolatilityRisk × 0.10 +
Score_PerformanceRisk × 0.20 +
Score_Profitability × 0.10 +
Score_Credibility × 0.10 +
Score_AIRisk × 0.10

text

- 最终得分区间：**0 ~ 100**
- 得分越高，策略越安全，越适合跟单。

## 五、策略筛选建议

| 综合评分区间 | 建议操作 |
|-------------|---------|
| **≥ 80** | **强烈推荐跟单** — 各项指标优秀，风险可控 |
| **60 ~ 79** | **可考虑跟单** — 整体良好，建议小仓位试跟 |
| **40 ~ 59** | **谨慎观察** — 存在明显风险点，需深入分析 |
| **< 40** | **不建议跟单** — 风险过高或数据不足 |

### 前置过滤条件
- 若 `trade_count < 20`，直接标记为 **“数据不足，不建议跟单”**，不进入评分流程。

## 六、数据来源与更新机制

- **数据来源**：Hyperliquid 账户交易记录、持仓数据、市场公共数据（TVL 等）
- **更新频率**：建议每日定时更新评分，确保跟单决策基于最新数据
- **权重调整**：可根据回测结果和风险偏好动态调整各维度权重
